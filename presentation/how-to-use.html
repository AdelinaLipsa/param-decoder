Mode · Postback

Set up a tracker postback right.

Paste the tracker’s postback URL to check it against the tokens BuyGoods actually fills — then copy the exact template for the affiliate’s tracker:

Voluum — cid carries the click ID, payout the revenue, txid the order ID.
CPV Lab — subid + revenue, called at adclick.php.
AnyTrack — click_id + value + transactionId.

Each one sourced from the tracker’s own docs, with a copy button.

● Param Decoder5

Mode · Decline

Explain a failed payment.

A decline code comes from the transaction — the backoffice, the gateway response, the customer’s error — not from a URL. Paste the code:

insufficient_fundssoft · worth a retry
Soft

Temporary

A retry can still go through — insufficient funds, issuer busy.

Hard

Permanent for this card

Expired, lost / stolen, do-not-honor — ask for a different card.

Tip: if a failure URL does carry the code, Inspect spots it inline.

Reading the screen

What the colours & badges mean.

Flags

Error — broken; usually a missing aff_id.
Warning — worth a look, won’t block.
OK — recognised and valid.
Heads-up — commission vs click-ID note.

Trust badges

confirmed
Team-trusted meaning.
inferred
A best guess — not yet verified.
noted
A meaning you saved on this device.
